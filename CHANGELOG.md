# Changelog

## [1.0.0] - 2026-09-06

- First release as a standalone Unity package.
- Extracted from ProjectY with history; runtime and editor code split into `Runtime/` and `Editor/`.
- Bundles its own `SerializableHashSet` / `SerializableDictionary` so the package has no external dependencies.
- Menu entries moved from `GameplayAbilitySystem/...` to `GameplayTags/...`.
